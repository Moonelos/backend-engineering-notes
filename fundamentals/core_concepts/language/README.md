# Python language

**Prerequisites:** Basic syntax and simple functions. This section explains the state and execution behind everyday Python.

## Reading order

| Lesson | Outcome |
|---|---|
| [Names and mutability](names_and_mutability.md) | Predict aliases, copying, identity and missing-value behavior |
| [Functions and scope](functions_and_scope.md) | Read signatures and explain defaults, closures and late binding |
| [Idioms and collections](idioms_and_collections.md) | Read unpacking, comprehensions, truthiness, sorting and matching |
| [Modules and imports](modules_and_imports.md) | Explain execution, caching and circular imports |
| [Decorators](decorators.md) | Trace rebinding, wrappers and registration after learning methods |
| [Standard-library tools](standard_library_tools.md) | Group/count/buffer values and compose callbacks and iterators |

## First result and stop point

The first two lessons let you predict state shared between calls and callbacks. Stop there when these are your immediate gaps. Continue to [Objects](../objects/README.md) for models. Read [iterators](../control_flow/iterators_and_generators.md) before the standard-library pipelines and [methods](../objects/classes_and_methods.md) before advanced decorators.
