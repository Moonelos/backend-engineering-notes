**Prerequisites:** Read [names and mutability](../language/names_and_mutability.md) and [functions and scope](../language/functions_and_scope.md) first.

## Reading order

| Lesson | Outcome |
|---|---|
| [Classes and methods](classes_and_methods.md) | Distinguish instance/class state, binding, inheritance and composition |
| [Attributes and introspection](attributes_and_introspection.md) | Read dynamic attributes and inspect objects |

## First result and stop point

Explain why a method receives an instance and a property needs no parentheses. Stop after entry 2 for everyday code. Continue into protocols when a framework hides behavior you need to diagnose. [Data models](../data_models/README.md) builds on the first two lessons.
